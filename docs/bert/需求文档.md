# 需求文档：本地部署与微调 BERT 用于虎扑电竞评论情感分类

> 版本：v1.0
> 日期：2026-08-13
> 关联项目：vct-quant（VCT CN 选手股量化系统）· 舆情层 / 评分层（RATING layer，复合定价权重 0.15）
> 作者：WorkBuddy

---

## 1. 背景与目标

VCT CN 选手股系统的复合定价公式为：

```
P = V* + 0.15 · 评分层偏离 + 0.05 · 地图层偏离
```

其中「评分层偏离」由虎扑（Hupu）赛后评分与评论舆情共同驱动。目前 `hupu_ratings_collector` 已能采集赛后评分与评论文本（`hupu_comments` 表），但评论本身只有原始文本，**缺少结构化情绪信号**。

本项目的目标：在**本地（离线、无外网依赖）** 微调一个中文 BERT 模型，对虎扑电竞评论做 **3 分类情感判断（正面 / 中性 / 负面）**，输出每条评论的情绪标签与置信度，供下游聚合为「选手/战队舆情情绪指数」，最终进入评分层偏离计算。

### 1.1 成功标准（初版）
- 验证集 **macro-F1 ≥ 0.80**
- 单条推理延迟：GPU < 50ms，CPU < 200ms
- 全链路可在无外网环境下训练与推理（权重、依赖均本地化）

---

## 2. 范围

### In Scope
1. 虎扑电竞评论情感标注规范与标注数据制备
2. 基于 `hfl/chinese-roberta-wwm-ext` 的本地微调（训练 / 验证 / 早停 / 评估）
3. 本地推理封装（批量打分，落库 `hupu_comments.sentiment`）
4. 与 vct-quant 的集成接口（情绪聚合 → 评分层偏离）

### Out of Scope
- 实时爬虫（已有 `hupu_ratings_collector` 负责）
- 多模态（图片 / 表情包理解，初版仅文本）
- 跨语言 / 多任务（仅中文、仅 3 分类情感）

---

## 3. 模型选型

| 项 | 选择 | 说明 |
|---|---|---|
| 底模 | `hfl/chinese-roberta-wwm-ext` | 哈工大 LTP 组，12 层 / 768 隐层 / 12 头 / 约 102M 参数，全词掩码预训练，中文效果优于 `bert-base-chinese` 且体量相近 |
| 任务头 | 线性分类头 + Dropout(0.1) | 接 `[CLS]` 池化输出，3 分类 |
| 最大长度 | 128 token | 单条虎扑评论普遍 < 100 字，128 足够覆盖 |
| 精度 | 训练 fp32；推理可选 fp16 / int8 | 本地 CPU 推理可行 |

### 3.1 资源估算
- 训练（fp32，batch=16）：峰值显存 ≈ 1.5–2.0 GB（GPU）／ CPU 内存 ≈ 3 GB
- 推理（fp32）：CPU 单线程即可，内存 < 1.5 GB
- 模型权重体积：≈ 390 MB（含 tokenizer）

## 4. 数据需求

### 4.1 数据源
- 主源：`hupu_comments` 表（赛后评论文本 + `match_id` + 关联选手/战队）
- 辅助增强（可选）：虎扑其他体育/电竞板块评论、公开电竞论坛语料

### 4.2 标注体系（3 类）
| 标签 | 含义 | 示例 |
|---|---|---|
| `positive` | 赞赏、支持、正向情绪 | “这波ZmjjKK 残局太帅了”、“今天状态拉满” |
| `neutral` | 客观陈述、无情绪、提问、闲聊 | “比赛几点开始”、“他用的什么枪” |
| `negative` | 批评、嘲讽、负面情绪 | “这操作看得我血压高”、“状态稀烂下场吧” |

> 标注细则见《提示词.md · 数据标注提示词》。重点处理：虎扑黑话、反讽、阴阳怪气、战队粉互喷。

### 4.3 数据规模与格式
- 建议标注量：**≥ 2000 条**，三类尽量均衡（偏差 ≤ 1.5:1）
- 格式：JSONL，每行 `{"text": "...", "label": "positive|neutral|negative", "match_id": "...", "player": "...", "source": "hupu"}`
- 切分：分层抽样 训练:验证 = 8:2，固定 random_seed 保证可复现

### 4.4 隐私与合规
- 仅使用公开评论文本；**不采集 / 不存储用户昵称、头像、私信等 PII**
- 标注与训练数据本地留存，不外传

---

## 5. 微调方案

### 5.1 技术栈
- Python 3.13（与 vct-quant 一致）
- `transformers` + `torch` + `datasets`（本地 venv 安装）
- 训练脚本本地化，支持 `OFFLINE_MODE`

### 5.2 超参数（基线）
| 参数 | 值 |
|---|---|
| epochs | 3–5（早停在 best macro-F1） |
| learning_rate | 2e-5 |
| batch_size | 16（GPU）/ 8（CPU） |
| max_seq_length | 128 |
| warmup_ratio | 0.1 |
| weight_decay | 0.01 |
| optimizer | AdamW |
| seed | 42 |

### 5.3 评估
- 指标：Accuracy、**Macro-F1**、每类 Precision/Recall、混淆矩阵
- 保存：按验证集 macro-F1 最优存 checkpoint
- 复现：固定 seed、固定 tokenizer 版本、记录 transformers/torch 版本

---

## 6. 部署与推理

### 6.1 模型产物
- 保存路径：`./models/sentiment-roberta/`（含 `pytorch_model.bin` / `config.json` / `tokenizer*`）
- 可选导出：ONNX / int8 量化，用于更低延迟 CPU 推理

### 6.2 本地推理服务
- 用 FastAPI 封装 `/predict`（单条）与 `/predict_batch`（批量）
- 输入：评论文本；输出：`{label, score, neg/neu/pos_probs}`
- 批量模式：读取 `hupu_comments` 未打分记录 → 写回 `sentiment` / `sentiment_score` 字段

### 6.3 离线保障
- 训练前预下载权重与 tokenizer 到本地缓存
- `requirements.txt` 锁定版本；安装镜像指向本地或已缓存 wheel

---

## 7. 与 vct-quant 集成

```
hupu_comments.text
      │  (本地 BERT 推理)
      ▼
hupu_comments.sentiment / sentiment_score
      │  (按 match_id + 选手聚合: 正向占比 - 负向占比)
      ▼
舆情情绪指数  →  RATING layer 偏离  →  P = V* + 0.15·评分层偏离 + 0.05·地图层偏离
```

- 落库字段建议：`sentiment`（标签）、`sentiment_pos/neu/neg`（概率）、`sentiment_updated_at`
- `value_model.rating_deviation` 读取聚合后的情绪指数，与虎扑评分共同构成评分层

## 8. 验收标准

| 维度 | 标准 |
|---|---|
| 模型质量 | 验证集 macro-F1 ≥ 0.80，且 negative 类 recall ≥ 0.75（负面最易漏判） |
| 性能 | GPU 单条 < 50ms；CPU 单条 < 200ms（batch=32 平均） |
| 工程 | 全链路离线可训练、可推理；脚本幂等可重跑 |
| 集成 | 推理结果正确落 `hupu_comments` 并被 value_model 读取聚合 |
| 文档 | 标注规范、训练命令、推理接口均有记录 |

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 标注一致性低（阴阳怪气难判） | 标签噪声 → F1 上不去 | 双人标注 + Kappa ≥ 0.7；给 few-shot 示例 |
| 类别不平衡 | 少数类 recall 低 | 分层抽样 + class_weight / focal loss |
| 虎扑黑话/梗外溢 | 域外泛化差 | 标注时收录高频黑话；保留未登录词 |
| 本地算力不足 | 训练慢 | 小 batch + 梯度累积；CPU 也能跑通基线 |
| 权重下载失败（外网受限） | 无法启动 | 预下载到本地缓存，离线加载 |
