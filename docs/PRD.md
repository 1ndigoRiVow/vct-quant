## 1. 背景与问题

### 1.1 我们在做什么
为 **VCT CN（无畏契约中国赛区）** 构建一个"**虎扑选手股**"量化预测与自动交易策略系统。把每名职业选手当作一支"股票"：
- **股价 = 社区人气**（虎扑赛后评分、讨论热度）
- **内在价值 = 客观比赛实力**（基于 KDA / ACS / 首杀 / 地图胜率等真实数据建模）
- **交易逻辑 = 人气与实力的偏离**：人气被低估则"买入"，被高估则"卖出"

### 1.2 核心洞察（产品的哲学根基）
"选手股"本质上是一个**人气预测问题**，等价于金融里的资产定价：

> 价格（人气水平）不可直接预测，但**价格的漂移（收益率/人气变化）是可预测的**。

类比金融的核心纪律，本产品坚持两条原则：
1. **股价由客观比赛表现主导（约 80%）**：选手股涨跌的主要驱动力是 KDA / ACS / 首杀 / 胜负等可量化的比赛数据，不是社区情绪；
2. **虎扑 JR 评分只是辅助情绪层（约 15%）**：它带来滞后与噪声，是"溢价/折价"的来源，但不是定价主轴；
3. **地图胜负为微小调整（约 5%）**：仅在具体地图维度上做边际修正。

因此：**第二层不该去硬猜"整体人气值"，而应聚焦预测那 15% 评分层相对表现的滞后与偏离**（条件期望 E[ΔRating]）；真正的 alpha 大头在"前瞻预测 80% 表现层"——这把问题从"猜一个噪声主导的水平"转化为"学一个可解释的反应函数"。

### 1.3 要解决的痛点
- 股价 80% 由客观表现决定，但市场用的是**事后/历史**表现来定价，缺乏对"下一场前瞻表现惊喜"的预测——这是最大的 alpha 来源；
- 虎扑评分（15%）存在滞后与过热：表现已变、评分未跟，或 JR 热议放大波动，缺乏量化刻画；
- 现有雏形只做"横截面 V\* 与 P 的静态比较"，没有**前瞻**——无法回答"下一场比赛后表现层会超/低于预期多少"；
- 比赛结果对评分层（15%）的影响函数（惊喜度反应）从未被建模，alpha 残留在系统性偏差里。

## 2. 目标与范围

### 2.1 目标（In Scope）
- **表现层（主导，≈80%）**：从客观比赛数据产出**不随时间剧烈波动的选手综合实力值 V\***，并附**赛前胜率预测 p̂**——这是股价主轴与主要 alpha 来源；
- **评分层（辅助，≈15%）**：融合 V\* + p̂ + 虎扑评分/舆情 + 动量，预测**评分层相对表现的滞后/偏离漂移 E[ΔRating]**，并给出置信区间——这是情绪溢价/折价的来源；
- **地图层（微调，≈5%）**：在具体地图维度上做胜负重加权边际修正；
- 交易层：当"前瞻表现 + 评分偏离"综合预期低于当前定价时发出买入信号，反之为卖出信号；多空组合、半凯利仓位、walk-forward 回测；
- 输出层：可复现的 HTML 信号报告 + Chart.js 仪表盘，支持每日定时运行。

### 2.2 非目标（Out of Scope，本阶段不做）
- **不做**模拟经营 / 战队管理游戏（那是 esports-manager 的定位，本项目只借鉴其引擎思路）；
- **不做**真实资金交易接口（系统输出"信号 + 仓位建议"，执行需人工或半自动网关，且涉及合规）；
- **不做**赛事结果直播 / 赔率对冲盘（仅用 VLR 数据建模，不接入博彩）；
- **不做**重深度学习黑箱（起步用可解释回归 / LightGBM，β 系数必须可读）。

## 3. 核心产品概念：表现主导 · 评分辅助的复合定价模型

选手股的"股价"不是单纯的人气值，而是一条**由规则决定的复合指数**。经核对实际涨跌规则：

> **股价 P = 0.80 × 表现层(Perf) + 0.15 × 评分层(Rating) + 0.05 × 地图层(Map)**

- 表现层（80%）：KDA / ACS / 首杀 FK / 首死 FD / 阵容 / 地图胜率等**客观比赛数据**；
- 评分层（15%）：虎扑 JR 赛后评分（`rating_avg`/`rating_count`）+ 评论情感，是**情绪溢价/折价**的来源；
- 地图层（5%）：该图胜负在地图维度的边际修正。

这意味着：**定价主轴是数据，评分只是辅助**——我们的核心引擎必须放在"前瞻预测 80% 表现层"，评分层是次要的情绪 tilt。

```
           股价 P = 0.80·Perf + 0.15·Rating + 0.05·Map
                     │            │             │
  ① 表现层(客观,80%)   ② 评分层(情绪,15%)  ③ 地图层(5%)
  输入: KDA/ACS/FK/FD   输入: 虎扑JR评分     输入: 该图胜负（小权重）
       /阵容/地图胜率        /评论情感            微调
  输出: V*(实力估值)      输出: E[ΔRating]    输出: 边际修正
       p̂(赛前胜率)          (情绪漂移, 带CI)
  特性: 平稳/可解释       特性: 滞后/噪声
       ── 主导 alpha ──    ── 辅助 tilt ──

  前瞻惊喜 s = 实际结果 − 赛前预测 p̂        （由第一层定义，喂入表现层与评分层）
  交易信号:
    主信号 = 预测 80% 表现层前瞻惊喜 s → 表现超/低于预期（最大 alpha）
    辅信号 = 15% 评分层相对表现的偏离(滞后/过热) → 确认或反向
    综合预期 < 当前定价 → 买入（洼地）；综合预期 > 当前定价 → 卖出（泡沫）
```

### 3.1 表现层：选手实力评分（客观、定价主轴、≈80%）
- **输入**：VLR.gg 客观比赛数据（KDA、首杀 FK、首死 FD、ACS、ADR、特工池、地图胜率、阵容）；
- **输出**：
  - `V*`：选手综合实力值（Glicko-2 评分体系，天然给出 rating / rd / vol，rd 表征不确定性）；
  - `p̂`：给定对阵双方的赛前胜率（FPS 回合制蒙特卡洛模拟器推导）——这是"前瞻表现惊喜"的基准。
- **特性**：客观、平稳、可解释——量化选手真实比赛影响力，是股价 80% 的成分，也是**主要 alpha 来源**（前瞻预测表现惊喜）。

### 3.2 评分层：虎扑 JR 评分情绪（辅助、≈15%）
- **输入**：第一层的 `V*` + `p̂` + 虎扑评分（`rating_avg`/`rating_count`）+ 评论情感 + 近期动量；
- **输出**：评分层相对表现的**漂移条件期望 `E[ΔRating]`**（含置信区间）——即"评分相对表现滞后/过热多少"；
- **反应函数（可学目标，仅针对 15% 这一层）**：
  ```
  ΔRating = α(热度) + β₁·s + β₂·动量 + γ·(Rating − Perf) + ε
   s = 实际结果 − 赛前预测概率 p̂               （惊喜度，由第一层定义）
  ```
  - `α(热度)`：热门选手评分波动放大（现象①）；
  - `β₁`：对"表现惊喜"的敏感度——冷门选手爆冷（s 为正且大）评分大涨、惜败（s 为负但小）评分不跌，体现凸性（现象②）；注意**凸性的主因是 80% 表现层被惊喜拉动，评分层只是放大器**；
  - `γ·(Rating−Perf)`：评分相对表现的偏离，滞后回归——这是次级 alpha（评分过热/过冷的反转）；
  - `ε`：评分存在不可预测随机噪声，模型输出置信区间，信号只在 E[ΔRating] 显著时触发。

### 3.3 交易信号
- 综合预期 = `0.80·Perf_forecast + 0.15·(Rating + E[ΔRating]) + 0.05·Map_adj`
- 综合预期 < 当前定价 → **买入**（被低估，看涨，按 A 股惯例标红）
- 综合预期 > 当前定价 → **卖出**（被高估，看跌，标绿）
- 主权重在表现层前瞻（80%），评分层（15%）做确认/反向 tilt，地图层（5%）微调；
- 仓位：半凯利（KELLY_FRACTION=0.5）× 信号强度；组合 dollar-neutral（多头空头净敞口 ≈ 0）。

## 7. 功能需求（FR）

### FR-1 数据采集
- FR-1.1 VLR.gg 采集比赛、地图比分、每名选手逐图统计（acs/kda/fk/fd/adr/agent/rounds）。
- FR-1.2 虎扑赛后评分采集：每名选手 `rating_avg` + `rating_count`（评分人数=热度代理），按 `match_id` 关联。
- FR-1.3 虎扑赛后评论采集：楼层/作者/内容/点赞/时间，供情感分析。
- FR-1.4 舆情（虎扑/贴吧）采集：帖子文本 + 时间 + 热度，BERT/LLM 情感打分。
- FR-1.5 增量幂等：同一 `match_id` 重跑不重复入库；离线合成模式全管线可零联网跑通。

### FR-2 第一层建模
- FR-2.1 Glicko-2 评分：`rate_all_players` 输出 `rating/rd/vol`，覆盖所有出场选手。
- FR-2.2 赛前胜率 `p̂`：`match_simulator.simulate_match` 蒙特卡洛 N=2000 次，输出 A 队胜率 + 95% 置信区间。
- FR-2.3 校准：`evaluate_calibration` 输出 Brier / LogLoss / 胜负命中率 + 每场明细；真实数据下改用 walk-forward 做 out-of-sample 校准。

### FR-3 评分层建模（Phase 2，辅助 ≈15%）
- FR-3.1 配对样本构造：每场比赛 `(赛前特征, 赛后评分变化)`，标签 = `Δrating_avg` 与/或 `Δrating_count`（相对该选手历史基线）。
- FR-3.2 特征工程：`s = Y − p̂`（表现惊喜度，主导 80% 层）、近期动量（近 N 场 KDA/ACS 趋势）、热度代理（rating_count 分位）、`Rating−Perf` 评分相对表现偏离。
- FR-3.3 反应函数估计：起步用 **事件研究回归（OLS）**，可解释 β；样本充足升级 **LightGBM**（保留特征重要性）。
- FR-3.4 输出 `E[ΔRating]` + 置信区间；只在置信区间不跨 0 且幅度超阈值时作为**辅助 tilt** 触发。

### FR-4 交易策略
- FR-4.1 信号：综合预期 `0.80·Perf_forecast + 0.15·(Rating+E[ΔRating]) + 0.05·Map_adj` 对比当前定价；BUY/SELL/HOLD（表现层前瞻为主，评分层为辅）。
- FR-4.2 仓位：半凯利 `KELLY_FRACTION=0.5` × 信号强度；组合 dollar-neutral（`MAX_POSITION_PCT=0.15`、最大回撤 `MAX_DRAWDOWN_PCT=0.20`）。
- FR-4.3 回测：walk-forward（`WALKFORWARD_TRAIN_DAYS=90`），输出净值、命中率、最大回撤。

### FR-5 输出
- FR-5.1 HTML 信号报告：信号明细、选手画像、战队地图胜率、p̂ 校准板块。
- FR-5.2 Chart.js 仪表盘：V\* vs P 散点、Δ 残差条、位置分布、ACS 排行、地图胜率 TOP、校准散点。
- FR-5.3 可重入：每日重跑不清空结构，仅 upsert 当日数据。

## 9. 成功指标 / 验收标准

- **第一层校准**：真实数据下 Brier < 0.25（优于随机）、LogLoss 收敛、胜负命中率 > 60%（walk-forward）。
- **表现层前瞻（核心）**：walk-forward 下赛前 p̂ 对实际表现惊喜 s 的方向命中率 > 60%，且前瞻表现因子对股价变动的解释力（R²）显著 > 仅用历史表现的基线。
- **评分层模型（辅助 15%）**：反应函数 β₁/β₂/γ 符号合理且显著；样本外 `E[ΔRating]` 对真实 `Δrating` 的 R² > 0 且有经济意义（仅 15% 权重，绝对幅度有限）。
- **策略回测**：接入真实数据后，净值显著优于买入持有 / 随机；最大回撤可控（< 30%）；信号命中率 > 静态 Δ 基线（当前 19.6% 偏低，需真实数据校准情绪定价）。
- **系统**：`python -m vct_quant.main` 离线零失败；真实模式每日可重入；报告/仪表盘板块完整渲染。

## 10. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 虎扑评分历史不可回溯 / 需登录 | 高 | Codex 采集器已支持匿名优先 + `HUPU_COOKIE` 环境变量 + 降级返回；评分是定格数据可回溯，评论可降级 |
| 表现层自噬（前瞻越准，历史表现定价越无效，信号越少） | 中 | alpha 残留在系统性偏差（颜值/主播溢价、实力型折价、冷门凸性）与评分层滞后——这些是模型学不会抹平的，重点挖掘 |
| 样本量小（VCT CN 比赛少） | 中 | 先做可解释回归 + 贝叶斯先验；跨赛区/跨赛季迁移；walk-forward 避免前视偏差 |
| 合成数据指标误导（如命中率 75% 含运气） | 中 | 明确标注"仅验证逻辑"；真实数据接入后重测所有指标 |
| 选手名对齐（VLR vs 虎扑昵称不一致） | 低 | 匹配不上原样落库，后续规则/人工对齐，不卡采集 |
| 真实数据接入网络阻塞（本环境 github:443 不通，已用 SSH 推；VLR/虎扑联网需另行验证） | 中 | 抓取下放沙箱 / 代理；或本机跑采集、推库 |

## 12. 术语表

| 术语 | 含义 |
|---|---|
| P | 选手股股价 = 0.80·表现层 + 0.15·评分层 + 0.05·地图层（复合指数） |
| Perf | 表现层（客观比赛数据，定价主轴 ≈80%） |
| Rating | 评分层（虎扑 JR 评分/舆情，情绪溢价 ≈15%） |
| Map | 地图层（该图胜负边际修正 ≈5%） |
| V\* | 第一层输出的选手综合实力估值（Glicko-2），≈表现层公平值 |
| p̂ | 赛前胜率预测（蒙特卡洛模拟器），前瞻表现惊喜的基准 |
| s | 表现惊喜度 = 实际结果 − p̂（主导 80% 层） |
| E[ΔRating] | 评分层相对表现的漂移条件期望（辅助可学目标，≈15%） |
| 选手股 | 把选手当股票：客观表现=定价主轴、虎扑评分=情绪辅助层 |
| 凸性 | 冷门选手爆冷大涨（主因 80% 表现层被惊喜拉动，15% 评分层放大） |
| 模型自噬 | 模型越准、定价越有效、套利空间越小 |
